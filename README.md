# 拾刻 Glint

拾刻 Glint 的 Android 安装包与更新清单。

Android 使用 ARM v8 Release 签名 APK。首次安装请从 [Releases](https://github.com/barks-sun/glint-releases/releases) 下载最新 APK；后续可在应用侧栏「应用更新」中检查、下载，再由 Android 系统确认安装。请保留原应用，覆盖安装即可保留本机内容与同步配置。

macOS 与 iOS 计划通过 App Store 分发，目前尚未发布；本仓库不提供这两个平台的安装包。

本仓库仅用于发布产物，不包含应用源码、签名私钥、服务商凭据或用户数据。同步使用用户自行配置的 WebDAV；更新服务器不接收收件箱内容。
